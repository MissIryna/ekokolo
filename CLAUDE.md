# Коло добрих екосправ

Гра для новацтва Пласту: 57 добрих справ для природи по порах року.
101 курінь УСП «Карпатські Вовки». Аудиторія — діти 8–11 років.

## Стек

Статичний `index.html` без збірки і без залежностей (крім шрифтів
Google) плюс Sinatra API поверх Postgres. Деплой — дроплет
DigitalOcean, nginx роздає статику й проксує `/api` в puma.

```
index.html          гра: розмітка, стилі, скрипт — усе в одному файлі
app.rb              API, Sinatra::Base, модульний стиль
config.ru           Rack entry point
db/schema.sql       схема, ідемпотентна
deploy/             systemd-юніт, фрагмент nginx
```

## Доменна мова

Говоримо термінами Пласту, не вигадуємо своїх:

- **новацтво** — діти 8–11; **новак** / **новачка** — одна дитина
- **Рій** — група новаків; **гніздо** — кілька Роїв
- **виховник** — дорослий, що веде Рій
- **сходини** — регулярна зустріч
- **проби** — програма вмінь; гра закриває підрозділ «довкілля»

**Рій** пишемо з великої літери в будь-якій формі: Рій, Рою (не «роя»),
Роєві, Рої, Роїв. В ідентифікаторах коду (`roi`, `grp`) — як є.

У коді й у текстах інтерфейсу — українська. Звертання до дитини на
«ти», речення короткі.

## Модель

`roi` — назва, унікальний чотирисимвольний код, ознака тестового.
`novak` — рядок на дитину: `roi_id`, `nick`, `nick_key` (lowercase),
`codes` (jsonb-масив ідентифікаторів справ), `cnt` (генерована з
`jsonb_array_length`), `updated_at`.
`board` — подання з сумами по Роях, тестові виключені.

Ключ новака — пара `(roi_id, nick_key)`. Прізвиська унікальні в межах
Рою; про це домовляються на сходинах.

## Рішення, які вже ухвалені

**Код Рою — спільний секрет.** Виховник створює Рій, отримує код,
роздає новакам. Без коду ні прочитати, ні записати поступ. Це вся
авторизація. Свідомо: восьмирічні не заводять облікових записів, а
найгірше, що зробить чужинець із кодом, — припише собі добрих справ.

**Merge на стороні бази.** `POST /api/progress` не замінює масив, а
зливає:

```sql
codes = (select coalesce(jsonb_agg(distinct e), '[]'::jsonb)
         from jsonb_array_elements(novak.codes || excluded.codes) e)
```

Причина: дитина грає з телефона й планшета, і last-write-wins з'їдав
би справи. Перевірено на 20 паралельних записах у той самий рядок.

**`GET /api/progress` рядка не створює.** Інакше кожен, хто просто
вписав прізвисько, роздував би лічильник новаків у Рої.

**Тестові Рої.** `roi.test = true` — Рій працює повністю, але в табло
не потрапляє. Щоб виховники перевіряли, не псуючи рахунок справжнім.

**Коди без I, O, S, 0, 1.** Діти плутають їх на слух і на вигляд.

**localStorage як запасний аеродром.** Сервер недоступний — гра далі
працює, поступ лежить у браузері й дописується, коли зв'язок
повернеться. Ніколи не ламай цю властивість.

**Жодного видалення через API.** Прибрати Рій чи новака можна тільки
руками в psql.

## Межі

Назва Рою і прізвисько — 24 символи. Не більше 200 справ на новака.
Тіло запиту — 64 КБ. Перевіряється і в коді, і в базі.

## Як запустити

```bash
createdb ekokolo && psql ekokolo -f db/schema.sql
cp .env.example .env            # підстав DATABASE_URL
bundle install
bundle exec puma -p 9292        # API
python3 -m http.server 8000     # статика, окремий термінал
```

`const API = ""` на початку скрипта в `index.html` означає «той самий
хост». Для розробки з двох портів постав `"http://localhost:9292"` і
додай `http://localhost:8000` в `ALLOWED_ORIGINS`.

З `file://` fetch не працює — тільки через http-сервер.

## Правила роботи з цим кодом

`index.html` лишається одним файлом без збірки. Це навмисно: гру має
бути легко скопіювати в інший курінь, віддати іншому виховнику,
відкрити й прочитати цілком. Не розбивай на модулі, не додавай
бандлер, не тягни фреймворк.

Не додавай залежностей без потреби. Поточні: sinatra, puma, sequel,
pg, rackup — і все.

Нові справи додаються в масив `D` у `index.html`. У кожної: пора
року `s`, категорія `c`, складність `lv` (1–3 листочки), емодзі `e`
для наліпки, назва `t`, опис `d`, факт `f` під скретчем, і `tg: 1`
якщо потрібен Рій або дорослий. Ідентифікатори `d1`…`dN`
проставляються автоматично за індексом — **не переставляй наявні
елементи масиву і не видаляй їх**, бо зсунуться ідентифікатори вже
записаних у базі справ. Нові дописуй у кінець своєї пори року.

Тексти справ пишемо для восьмирічного: одна дія, одне речення.
Факт під скретчем — те, чого дитина не знала, а не мораль.

## Відкриті питання

- `ekokolo.pp.ua` зараз вказує на GitHub Pages. Pages не проксує
  `/api`, тож домен має переїхати на дроплет (A-запис на його IP),
  і nginx роздаватиме статику й API разом.
- `limit_req` у `deploy/nginx.conf` стоїть 5r/s burst 20 — цифра
  взята зі стелі, варто звірити з рештою навантаження дроплета.
- Бекапи: `pg_dump` у cron раз на добу ще не налаштовано.
- Ruby-частина не проганялася end-to-end: SQL перевірено на живому
  Postgres 16, `bundle install` і перший запит — ні.

## Чого не робити

Не збирай персональних даних дітей. Тільки пластове прізвисько й
назва Рою — ні прізвищ, ні пошт, ні фотографій. Якщо колись
знадобляться фотозвіти, це окрема розмова про згоду батьків.
