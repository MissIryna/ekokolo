# Коло добрих екосправ

Гра для новацтва: 57 добрих справ для природи, розкладених по порах року.
101 курінь УСП «Карпатські Вовки».

Сайт — один файл `index.html`. Дані — звичайна Google Таблиця.
Нічого встановлювати не треба.

---

## 1. Створи таблицю

Нова Google Таблиця, назва будь-яка — наприклад «Коло добрих екосправ».
Аркуш із потрібними колонками скрипт створить сам при першому записі.

## 2. Встав скрипт

У таблиці: **Розширення → Apps Script**.
Видали те, що там є, і встав увесь вміст `apps-script.gs`.
Збережи.

## 3. Розгорни як веб-застосунок

У редакторі скрипта: **Розгорнути → Новий розгорнутий ресурс**.

- тип: **Веб-застосунок**
- виконувати від імені: **я**
- доступ: **усі** (саме «усі», інакше діти не зможуть писати)

Погодься з попередженням про небезпечний застосунок — це нормально для
власних скриптів, Google просто не перевіряв його публічно.

Скопіюй URL. Він виглядає так:
`https://script.google.com/macros/s/AKfy.../exec`

## 4. Встав URL у сайт

Відкрий `index.html`, знайди рядок:

```js
const API = "";
```

Встав туди свій URL:

```js
const API = "https://script.google.com/macros/s/AKfy.../exec";
```

Без цього кроку сайт працює, але поступ зберігається лише в браузері
дитини й табла Роїв немає.

## 5. Виклади на GitHub Pages

1. Новий **публічний** репозиторій.
2. Завантаж `index.html` у корінь.
3. **Settings → Pages**, джерело: гілка `main`, папка `/root`.
4. Там же **Custom domain**: `ekokolo.pp.ua`.
5. У nic.ua додай CNAME-запис `ekokolo.pp.ua` → `ТВІЙНІК.github.io`.
6. Коли DNS розійдеться — постав галочку **Enforce HTTPS**.

## Як це працює

Дитина відкриває сайт і вписує Рій та прізвисько. Ця пара — її ключ:
з будь-якого телефона вона побачить свої наліпки.

У таблиці на кожного новака один рядок: Рій, прізвисько, перелік
виконаних справ, їхня кількість і час останньої зміни.
Табло Роїв рахується з цих рядків.

Прізвисько має бути унікальним у межах Рою. Якщо в одному Рої дві
Лисички — їхні справи змішаються. Домовтеся про це на сходинах.

## Якщо щось не працює

**Табло порожнє, поступ не зберігається** — найчастіше в розгортанні
стоїть доступ «лише я» замість «усі». Перерозгорни.

**Змінив скрипт, а нічого не змінилося** — Apps Script оновлює
веб-застосунок лише при новому розгортанні. Розгорнути → Керувати →
олівець → нова версія.

**Діти бачать чужі справи** — збіглися прізвиська в одному Рої.

## Що варто знати

Таблиця відкрита на запис для кожного, хто має адресу сайту. Хтось може
вписатися чужим прізвиськом або накрутити собі справ. Для одного гнізда
це радше жарт, ніж загроза, але якщо заважатиме — додається кодове
слово гнізда.

Резервна копія: **Файл → Створити копію** раз на сезон. Достатньо.
