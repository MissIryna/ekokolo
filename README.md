# Коло добрих екосправ

Гра для новацтва Пласту: 62 добрі справи для природи, розкладених по
порах року. 101 курінь УСП «Карпатські Вовки».

Живе на https://ekokolo.pp.ua

## Як це працює

Виховник створює Рій і отримує чотирисимвольний код. Новаки вписують
код Рою і своє прізвисько — і з будь-якого телефона бачать свої
наліпки. Табло Роїв рахує, скільки добрих справ зібрав кожен Рій.

Прізвисько має бути унікальним у межах Рою. Якщо в одному Рої дві
Лисички — їхні справи змішаються. Домовтеся про це на сходинах.

Тестовий Рій працює так само, але в табло не потрапляє — щоб
виховники могли спробувати, не псуючи рахунок.

Якщо сервер недоступний, гра працює далі: поступ лежить у браузері
й дописується, щойно зв'язок повернеться.

## Що тут лежить

```
index.html      гра: розмітка, стилі, скрипт — усе в одному файлі
app.rb          API на Sinatra
db/schema.sql   схема Postgres
deploy/         systemd, nginx, бекап і покрокове розгортання
```

## Запустити в себе

```bash
createdb ekokolo && psql ekokolo -f db/schema.sql
cp .env.example .env
bundle install
set -a; . ./.env; set +a
bundle exec puma -p 9292        # API
python3 -m http.server 8000     # гра, в окремому терміналі
```

Для розробки з двох портів у `index.html` постав
`const API = "http://localhost:9292"`.

Розгортання на сервері — [deploy/DEPLOY.md](deploy/DEPLOY.md).
Усі ухвалені рішення й правила роботи з кодом — [CLAUDE.md](CLAUDE.md).

## Що ми не збираємо

Тільки пластове прізвисько й назву Рою. Ні прізвищ, ні пошт, ні
фотографій.
